# Personal Resume Website

This is my **first personal resume website**, created in 2024 as one of my first projects while learning web development.

The project was built to introduce myself, share my educational background, and present my early experience with programming and web technologies.

## About the Project

This website represents an early stage of my journey in software development. I created it while learning the fundamentals of HTML and CSS and experimenting with how a personal portfolio/resume website could be structured.

It is a simple project, but it is an important part of my development journey because it was one of the first websites I built from scratch.

## Technologies

- HTML5
- CSS3

## Features

- Personal introduction
- Educational background
- Programming interests
- Basic resume information
- Simple and responsive page structure

## Project History

**Created:** 2024

This project is kept as an archive to document my progress and development as a programmer.

Since creating this website, I have continued improving my programming skills and have worked with technologies such as C++, C#, Python, JavaScript, SQL, OpenCV, and other development tools.

## Purpose

The purpose of this project is not to represent my current skill level, but to preserve and demonstrate where my web development journey began.

> Every project is a step forward. This was one of my first steps.
